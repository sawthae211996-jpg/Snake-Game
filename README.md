# 🐍 မြွေဂိမ်း (Snake Game)

HTML, CSS, JavaScript နဲ့ ဖန်တီးထားတဲ့ ရိုးရှင်းတဲ့ မြွေဂိမ်း။

## 🎮 ဘယ်လိုဆော့မလဲ

- **ဖုန်း**: Swipe ဒါမှမဟုတ် ခလုတ်တွေ နှိပ်ပါ
- **ကွန်ပျူတာ**: Arrow keys ဒါမှမဟုတ် WASD နှိပ်ပါ

## ✨ အင်္ဂါရပ်များ

- Mobile-friendly
- Swipe ထိန်းချုပ်မှု
- Score system
- အမြန်နှုန်း တဖြည်းဖြည်း တက်
